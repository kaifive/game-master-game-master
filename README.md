# Game Master

Party games for live events. Players scan a QR code, pick a nickname and a
team, then play quick solo mini games and host-run live games from their
phones. The host runs it all from an admin dashboard, with a big-screen
display for the room.

- Each event has its own URL (`/winter-2026`), and its games live under it.
- Every past event stays in the library.
- Games are generic and themeable: one word game can be reskinned for a
  holiday party without changing its logic.
